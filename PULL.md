# Pull / clone this extension

Canonical tree: **https://github.com/adeotale27/Market_Events** (`main`).

```bash
git clone https://github.com/adeotale27/Market_Events.git
cd Market_Events
```

Load unpacked: Chrome → `chrome://extensions` → Developer mode → **Load unpacked** → this folder (`manifest.json` is in the root).

The first copy of these files lived on **oi-pulse-app** orphan branch `cursor/market-events-1bf9` (Pulse app files are not on that branch). That branch is history only. **Do not** merge it into OI Pulse `main`.
