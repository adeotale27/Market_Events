Admin desk

Traders never see this page. Sign in to upload calendars for this browser, or commit the same JSON on GitHub for everyone.

Admin uploads

Accepts UTF-8 .json only. FII/DII and live index prints are never uploaded — those come from NSE / Yahoo in the user’s Chrome.

Each index-risk file is treated as ~30 days from its updated date.

1. Holidays

File: holidays.json · NSE trading holidays.

{
  "holidays": [
    { "date": "2026-09-14", "name": "Ganesh Chaturthi" }
  ]
}

date must be YYYY-MM-DD. name is the holiday title.

2. Next Event (macro)

File: econ-events.json · RBI, FOMC, CPI, GDP, Budget, NFP.

{
  "events": [
    { "date": "2026-08-31", "name": "India GDP Q1 FY27", "type": "gdp", "country": "IN", "impact": "high" }
  ]
}

impact is one of critical | high | medium | low.

3. Index risk (one file per index)

Files: NIFTY.json, SENSEX.json, BANKNIFTY.json. Only Quarterly Results and Board Meeting rows are shown. Join constituents yourself (name + weightage).

{
  "index": "NIFTY",
  "updated": "2026-08-14",
  "events": [
    {
      "name": "Reliance Industries",
      "symbol": "RELIANCE",
      "date": "2026-08-20",
      "event_type": "Quarterly Results",
      "weightage": 8.7
    }
  ]
}

4. Shared GitHub server

Installed copies fetch JSON from this raw base (default Market_Events main). Leave as-is unless you fork.
